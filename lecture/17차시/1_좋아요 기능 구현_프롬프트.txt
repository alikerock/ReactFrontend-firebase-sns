현재 React + Firebase Firestore로 구현된 SNS 프로젝트의 게시글에 **좋아요 기능**을 추가해줘.

구현 요구사항

1. 각 게시글에 좋아요 버튼과 좋아요 개수를 표시한다.
2. 좋아요 데이터는 각 게시글의 `likes` 서브컬렉션에 저장한다.
3. 좋아요 문서의 ID는 로그인한 사용자의 `user.uid`를 사용한다.
4. 로그인한 사용자만 좋아요 기능을 사용할 수 있도록 한다.
5. 사용자가 좋아요하지 않은 상태에서 버튼을 클릭하면 `setDoc()`을 사용하여 좋아요를 등록한다.
6. 이미 좋아요한 상태에서 다시 클릭하면 `deleteDoc()`을 사용하여 좋아요를 취소한다.
7. 현재 로그인한 사용자의 좋아요 여부를 확인하여 버튼 또는 아이콘의 활성 상태를 다르게 표시한다.
8. `likes` 서브컬렉션의 문서 수를 조회하여 좋아요 개수로 표시한다.
9. 좋아요 등록 또는 취소 후 버튼 상태와 좋아요 개수가 화면에 바로 반영되도록 React State를 사용한다.
10. 기존 게시글 조회, 수정, 삭제 기능은 변경하지 않는다.
11. 기존 프로젝트 구조와 UI 스타일을 최대한 유지하고, 필요한 코드만 수정한다.

Firestore 데이터 구조는 다음과 같이 구성한다.

posts
└─ {postId}
　└─ likes
　　　└─ {user.uid}

좋아요 문서에는 다음 정보를 저장한다.

* `uid`: 로그인 사용자 UID
* `createdAt`: `serverTimestamp()`

먼저 현재 프로젝트의 게시글 관련 컴포넌트 구조를 확인한 후, 어떤 파일을 수정해야 하는지 설명하고 필요한 코드만 단계별로 구현해줘.
