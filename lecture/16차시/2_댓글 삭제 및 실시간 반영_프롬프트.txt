현재 게시글 상세 페이지에
댓글 실시간 조회와 댓글 삭제 기능을 추가해줘.

[구현 요구사항]

1. Firestore comments 컬렉션에서
   현재 게시글의 postId와 일치하는 댓글만 조회한다.

2. 댓글 목록은 getDocs() 방식이 아니라
   onSnapshot()을 사용하여 실시간으로 구독한다.

3. 댓글 데이터가 추가되거나 삭제되면
   새로고침 없이 React 화면에 즉시 반영되도록 한다.

4. 댓글은 createdAt 기준 오래된 순으로 정렬하여
   작성 순서대로 표시한다.

5. 각 댓글에는 기존 UI 구조에 맞게 다음 정보를 출력한다.
   - 작성자 이름
   - 프로필 이미지
   - 댓글 내용

6. 현재 로그인한 사용자의 uid와
   댓글 작성자의 uid가 같은 경우에만
   [삭제] 버튼을 표시한다.

7. [삭제] 버튼 클릭 시
   Firestore의 해당 댓글 문서를 deleteDoc()으로 삭제한다.

8. 삭제 전 사용자에게 확인 과정을 추가한다.

9. 댓글 삭제가 완료되면
   별도의 재조회 없이 onSnapshot()을 통해
   변경된 댓글 목록이 자동으로 반영되도록 한다.

10. 댓글이 없는 경우에는
    "아직 작성된 댓글이 없습니다."와 같은 안내 메시지를 표시한다.

11. 데이터 조회 중에는 로딩 상태를 처리한다.

12. 조회 또는 삭제 과정에서 오류가 발생하면
    사용자에게 오류 메시지를 표시하고
    console에서도 원인을 확인할 수 있도록 처리한다.

13. useEffect() 내부에서 onSnapshot()을 등록하고,
    컴포넌트가 사라질 때 unsubscribe()를 호출하여
    실시간 구독을 해제한다.

[실시간 댓글 조회 흐름]

게시글 ID 확인
→ comments 컬렉션 조회
→ where("postId", "==", postId)
→ orderBy("createdAt", "asc")
→ onSnapshot() 실시간 구독
→ React State 업데이트
→ 댓글 목록 출력

[댓글 삭제 흐름]

현재 사용자 uid 확인
→ 댓글 작성자 uid 비교
→ 본인 댓글에만 삭제 버튼 표시
→ deleteDoc()
→ Firestore 데이터 삭제
→ onSnapshot() 변경 감지
→ 화면 자동 갱신

[중요]
- 기존 댓글 작성 기능은 그대로 유지한다.
- 현재 게시글 상세 페이지의 UI와 스타일은 변경하지 않는다.
- 기존 Firebase 설정 파일을 재사용한다.
- 현재 프로젝트의 컴포넌트 구조와 코딩 방식을 유지한다.
- 불필요하게 다른 컴포넌트나 페이지는 수정하지 않는다.
