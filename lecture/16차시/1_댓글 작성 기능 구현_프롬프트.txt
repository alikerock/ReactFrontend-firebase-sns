현재 구현되어 있는 게시글 상세 페이지에
Firebase Firestore를 이용한 댓글 작성 기능을 추가해줘.

[구현 요구사항]

1. 기존 댓글 입력 UI와 디자인은 그대로 유지한다.

2. Firebase Authentication을 이용하여
   현재 로그인한 사용자를 확인한다.

3. 사용자가 댓글을 입력하고 [등록] 버튼을 클릭하면
   Firestore의 comments 컬렉션에 댓글을 저장한다.

4. 댓글 저장 시 다음 정보를 포함한다.
   - postId: 현재 게시글의 ID
   - uid: 로그인 사용자의 uid
   - displayName: 작성자 이름
   - photoURL: 작성자의 프로필 이미지
   - content: 댓글 내용
   - createdAt: serverTimestamp()

5. 댓글 내용이 비어 있는 경우에는 저장하지 않는다.
   공백만 입력한 경우도 등록되지 않도록 trim()을 사용한다.

6. 로그인하지 않은 사용자는 댓글을 작성할 수 없도록 처리한다.

7. 댓글 저장이 완료되면 댓글 입력창을 초기화한다.

8. 댓글 저장 중에는 등록 버튼을 비활성화하여
   중복 등록을 방지한다.

9. 댓글 등록에 실패하면
   오류 내용을 확인할 수 있도록 예외 처리를 추가한다.

[댓글 저장 흐름]

댓글 입력
→ 로그인 사용자 확인
→ 입력값 검사
→ 현재 게시글 ID 확인
→ addDoc()
→ Firestore comments 컬렉션 저장
→ 입력창 초기화

[중요]
- 기존 게시글 상세 페이지의 UI와 스타일은 변경하지 않는다.
- 기존 Firebase 설정 파일을 재사용한다.
- 현재 프로젝트의 컴포넌트 구조와 코딩 방식을 유지한다.
- 게시글 수정/삭제 등 기존 기능은 수정하지 않는다.
- 이번 작업에서는 댓글 작성 기능을 중심으로 구현한다.
