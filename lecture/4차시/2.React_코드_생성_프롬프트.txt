첨부된 DevLog 디자인을 참고하여 **React(Vite) 기반의 프론트엔드 프로젝트**를 생성해 주세요.

## 1. 개발 환경

* React + Vite
* **JavaScript 기반으로 작성**
* TypeScript는 사용하지 않음
* JSX 사용
* React Router DOM 사용
* Material UI(MUI) 사용
* MUI Icons 사용
* 함수형 컴포넌트 방식으로 작성

## 2. 구현할 페이지

첨부된 디자인을 참고하여 다음 페이지를 구성해 주세요.

* 로그인
* 회원가입
* 메인 피드
* 내 게시글
* 게시글 상세
* 게시글 작성
* 게시글 수정
* 프로필
* 프로필 수정
* 404 Not Found

React Router를 이용하여 각 화면을 별도의 URL로 이동할 수 있도록 구성해 주세요.

예시:

* `/`
* `/login`
* `/signup`
* `/posts/:id`
* `/posts/create`
* `/posts/:id/edit`
* `/my-posts`
* `/profile`
* `/profile/edit`
* `*` → 404 페이지

## 3. 공통 Layout 구성

로그인과 회원가입 페이지를 제외한 서비스 화면에는 첨부 디자인과 같이 공통 Layout을 적용해 주세요.

공통 Layout은 다음 영역으로 구성합니다.

* 상단 Header
* 왼쪽 Sidebar
* 중앙 콘텐츠 영역
* 필요한 페이지의 오른쪽 보조 콘텐츠 영역

Header, Sidebar 등 여러 페이지에서 반복되는 UI는 별도의 재사용 가능한 컴포넌트로 분리해 주세요.

React Router의 중첩 Route와 `Outlet`을 활용하여 공통 Layout 내부에서 페이지 콘텐츠가 변경되도록 구성해 주세요.

## 4. MUI 적용

화면 구성은 Material UI를 중심으로 구현해 주세요.

다음과 같은 MUI 컴포넌트를 적절히 활용해 주세요.

* AppBar
* Toolbar
* Drawer
* Box
* Container
* Stack
* Typography
* Button
* TextField
* Card
* Avatar
* IconButton

스타일은 가능한 한 MUI의 `sx`를 활용해 주세요.

## 5. Theme 구성

MUI `createTheme()`과 `ThemeProvider`를 이용하여 공통 Theme을 구성해 주세요.

첨부 디자인을 참고하여 다음 요소가 전체 화면에서 일관되게 적용되도록 합니다.

* DevLog의 파란색 계열 Primary Color
* 배경색
* 텍스트 색상
* 버튼 스타일
* Card 스타일
* border-radius
* Typography

`CssBaseline`도 적용해 주세요.

## 6. 반응형 UI

MUI breakpoint를 활용하여 기본적인 반응형 Layout을 구성해 주세요.

* Desktop에서는 Header + Sidebar + Content 구조 유지
* 화면이 작아지면 콘텐츠 너비가 자연스럽게 축소
* 모바일에서는 Sidebar를 숨기거나 Drawer 형태로 전환
* 게시글 Card와 입력 Form은 모바일에서 화면 너비에 맞게 표시

별도의 복잡한 CSS 미디어쿼리보다는 MUI의 `sx` breakpoint 기능을 우선 사용해 주세요.

## 8. 데이터 처리 범위

이번 단계에서는 **Firebase 또는 실제 백엔드와 연결하지 않습니다.**

화면 확인에 필요한 게시글, 사용자, 댓글 등의 데이터는 JavaScript 객체 또는 배열 형태의 **Mock Data**를 만들어 사용해 주세요.

로그인, 회원가입, 게시글 등록·수정·삭제 등의 버튼은 UI와 페이지 이동을 확인할 수 있는 수준까지만 구현합니다.

실제 인증, 데이터베이스 저장, 파일 업로드 기능은 구현하지 않습니다.

## 10. 최종 구현 목표

이번 단계의 목표는 실제 서비스 기능 완성이 아니라,

**Figma 디자인 → React 컴포넌트 분리 → React Router 페이지 구성 → MUI 공통 Layout → Theme 적용 → 반응형 UI**

순서로 DevLog 서비스의 프론트엔드 기본 구조를 완성하는 것입니다.

코드는 초급 React 학습자가 이해할 수 있도록 지나치게 복잡한 패턴이나 상태관리 라이브러리는 사용하지 말고 간결하게 작성해 주세요.
