React와 Material UI(MUI)를 기반으로 구현하기 쉬운 SNS 웹서비스를 디자인해 주세요.

목표는 교육용 프로젝트이며, 초급 React 개발자가 그대로 구현할 수 있는 수준이어야 합니다.

기술블로그의 형태로 지식을 포스트하고 공유할 수 있는 SNS 서비스의 디자인을 생성한다.

다음 화면을 포함한 웹 애플리케이션을 설계합니다.

- 로그인, 회원가입(비밀번호, 이메일, 또는 SNS)
- 메인 피드
- 게시글 작성
- 게시글 상세
- 프로필
- 내 게시글
- 게시글 수정
- 404 페이지

디자인 요구사항

- Material UI 컴포넌트를 그대로 활용할 수 있는 구조
- 복잡한 애니메이션 제외
- Glassmorphism, Neumorphism 등 구현 난이도가 높은 디자인 제외
- 카드(Card), 버튼(Button), AppBar, Drawer, Avatar, TextField, Dialog 등 MUI 기본 컴포넌트 중심
- 반응형을 고려하되 모바일 우선이 아닌 데스크톱 기준
- CSS가 복잡하지 않도록 구성
- Grid와 Flex 레이아웃 위주
- 그림자 효과는 최소한으로 사용
- border-radius는 8~12px 정도의 단순한 형태
- 컬러는 MUI 기본 Blue 계열 Primary Color 사용
- 아이콘은 Material Icons 사용
- 이미지 영역은 Placeholder 형태로 표현

메인 피드 화면은 다음 요소를 포함합니다.

- 상단 AppBar
- 좌측 메뉴(Drawer)
- 중앙 게시글 리스트
- 게시글 카드
- 작성자 프로필
- 작성일
- 게시글 내용
- 이미지
- 좋아요 버튼
- 댓글 버튼

게시글 작성 화면은

- 제목
- 내용
- 이미지 업로드
- 등록 버튼

정도의 단순한 구성으로 설계합니다.

프로필 화면은

- 프로필 이미지
- 사용자 이름
- 자기소개
- 작성한 게시글 목록

정도로 단순하게 구성합니다.

전체 디자인은

"교육용 SNS 서비스"

수준으로 단순하고 직관적이며 React 초급자가 그대로 구현할 수 있는 수준으로 제작해 주세요.

- 컴포넌트 개수를 최소화합니다.
- 동일한 Card 디자인을 여러 화면에서 재사용할 수 있도록 구성합니다.
- 화면마다 디자인 스타일을 통일합니다.
- 커스텀 SVG, 복잡한 일러스트, 배경 패턴은 사용하지 않습니다.
- React 컴포넌트로 쉽게 분리 가능한 구조를 우선합니다.
- HTML과 Material UI만으로 구현 가능한 디자인을 생성합니다.
- Firebase Authentication, Firestore, Storage 기능을 연결하기 쉬운 UI 구조를 사용합니다.
