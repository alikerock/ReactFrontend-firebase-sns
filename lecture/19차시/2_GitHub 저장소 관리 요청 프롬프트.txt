현재 프로젝트를 GitHub 저장소에 최종 정리.

먼저 현재 Git 상태와 변경된 파일을 확인한 후
다음 항목을 기준으로 점검.

1. .gitignore에 불필요한 파일과 환경변수 파일이 제외되어 있는지 확인
2. .env, API Key 등 민감한 정보가 Git에 포함되어 있지 않은지 확인
3. 현재 변경된 파일을 확인하고 커밋에 포함할 파일 정리
4. 변경 내용을 기준으로 적절한 커밋 메시지 제안
5. README.md에 프로젝트 실행 방법, 주요 기능, 사용 기술이 정리되어 있는지 확인
6. GitHub에 push하기 전 최종 확인 사항 안내

기존 Git 히스토리는 변경하지 않고 파일도 임의로 삭제하지 않기.

commit, push 명령은 바로 실행하지 말고
먼저 실행할 명령과 작업 내용을 제안.
확인 후 실행할 수 있도록 대기.
