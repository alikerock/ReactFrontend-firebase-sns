현재 React 프로젝트의 전체 코드를 점검하고
최종 배포가 가능한 상태로 정리.

다음 기준으로 작업.

1. 사용하지 않는 import와 변수 제거
2. 불필요한 console.log()와 디버깅 코드 제거
3. 너무 크거나 복잡한 컴포넌트는 역할별로 분리
4. 중복 코드는 공통 함수 또는 컴포넌트로 정리
5. 기존 기능과 UI는 그대로 유지
6. ESLint 검사를 실행하고 발견된 오류 수정
7. npm run build를 실행하여 프로덕션 빌드 성공 여부 확인
8. 수정한 파일과 주요 변경 내용을 마지막에 요약

기존 프로젝트의 기능 유지를 가장 우선으로 하고,
불필요한 대규모 리팩토링은 진행하지 않기.
