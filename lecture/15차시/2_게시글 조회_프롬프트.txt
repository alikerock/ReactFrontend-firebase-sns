현재 구현되어 있는 "내 게시글" 페이지에 Firebase Firestore를 연동하여
로그인한 사용자가 작성한 게시글만 조회하도록 구현해줘.

[구현 요구사항]

1. Firebase Authentication에서 현재 로그인한 사용자를 확인한다.

2. 로그인 사용자의 uid를 가져온다.

3. Firestore posts 컬렉션에서
   게시글의 uid 값이 현재 로그인 사용자의 uid와 같은 게시글만 조회한다.

   예:
   where("uid", "==", user.uid)

4. 조회된 게시글은 작성일(createdAt) 기준 최신순으로 정렬한다.

5. 조회된 데이터를 현재 구현되어 있는 "내 게시글" 카드 UI에 출력한다.

6. 각 게시글에는 기존 데이터 구조에 맞게 다음 정보를 출력한다.
   - 작성자 이름
   - 프로필 이미지
   - 작성 시간
   - 게시글 제목
   - 게시글 내용
   - 게시글 이미지
   - 좋아요 수
   - 댓글 수

7. 게시글 이미지가 없는 경우에는
   깨진 이미지나 빈 이미지 영역이 표시되지 않도록 처리한다.

8. 현재 사용자가 작성한 게시글이 하나도 없는 경우에는
   기존 빈 상태 UI를 표시한다.

   예:
   "아직 작성한 게시글이 없습니다."
   "첫 번째 글을 작성해 보세요!"

9. 데이터 조회 중에는 로딩 상태를 표시한다.

10. Firestore 조회 과정에서 오류가 발생하면
    사용자에게 오류 메시지를 표시하고
    console에서도 원인을 확인할 수 있도록 처리한다.

11. 로그인하지 않은 사용자가 접근하면
    로그인 페이지로 이동하도록 처리한다.

12. 기존에 구현된 수정(Edit), 삭제(Delete) 버튼과
    게시글 작성 버튼은 그대로 유지한다.

[Firestore 조회 흐름]

Firebase Authentication
→ 현재 사용자 확인
→ user.uid 확보
→ posts 컬렉션 조회
→ where("uid", "==", user.uid)
→ 최신순 정렬
→ React State 저장
→ 내 게시글 화면 출력

[중요]
- 현재 UI와 스타일은 변경하지 않는다.
- 기존 Firebase 설정 파일을 재사용한다.
- 기존 posts 컬렉션의 필드 구조를 확인한 후 그 구조에 맞춰 구현한다.
- 이미 구현되어 있는 게시글 수정/삭제 기능은 변경하지 않는다.
- 불필요하게 다른 컴포넌트나 페이지를 수정하지 않는다.
