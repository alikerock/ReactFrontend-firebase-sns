현재 게시글 작성 기능과 이미지 업로드 기능을 점검하고,
Firebase 보안 규칙에 맞도록 필요한 부분만 수정해줘.

적용된 보안 규칙은 다음과 같다.

1. Firestore
- 로그인한 사용자만 posts 컬렉션에 게시글을 작성할 수 있다.
- 게시글 생성 시 uid 필드에는 반드시 현재 로그인 사용자의 uid를 저장해야 한다.

2. Firebase Storage
- 로그인한 사용자만 이미지를 업로드할 수 있다.
- 이미지 저장 경로는 다음 구조를 사용한다.
  posts/{user.uid}/{fileName}
- 다른 사용자의 경로에는 파일을 업로드할 수 없다.

글 생성 시 처리 순서:
1. 현재 로그인 사용자를 확인한다.
2. 로그인하지 않은 경우 글 작성과 이미지 업로드를 진행하지 않는다.
3. 이미지가 있으면 Storage의 posts/{user.uid}/{fileName} 경로에 업로드한다.
4. 업로드 완료 후 이미지 URL을 가져온다.
5. Firestore posts 컬렉션에 게시글을 저장한다.
6. 게시글 데이터의 uid에는 현재 로그인 사용자의 uid를 저장한다.
7. 이미지가 있으면 다운로드 URL도 함께 저장한다.
8. Firebase 작업은 try...catch...finally로 처리한다.
9. 처리 중에는 중복 등록을 방지할 수 있도록 버튼을 비활성화한다.
10. 실패하면 콘솔에서 원인을 확인할 수 있도록 오류를 출력한다.

주의:
- 기존 UI와 정상적으로 동작하는 기능은 변경하지 않는다.
- 불필요한 컴포넌트 리팩토링은 하지 않는다.
- 현재 프로젝트의 필드명과 코드 구조를 먼저 확인한 후 기존 구조에 맞게 수정한다.
- 수정한 코드와 수정 이유를 간략하게 설명한다.
